# Автоматизированная актуализация базы знаний предметных отраслей науки

**Тема ВКР:** Исследование и разработка технологий автоматизированной актуализации базы знаний предметных отраслей науки.

**Научный руководитель:** Хорошилов Александр Алексеевич  
**Образовательная организация:** МАИ, Образовательный центр Института №8

## Описание проекта

Проект посвящён разработке интеллектуальной системы автоматизированного формирования и актуализации научно-технических баз знаний с использованием больших языковых моделей (LLM) и AI-агентов.

Система предназначена для обработки научно-технических документов из различных предметных областей, извлечения терминов и семантических отношений, формирования онтологий и обнаружения пробелов в существующих знаниях.

Ключевая особенность — использование LLM-агента, который самостоятельно ищет научные публикации для восполнения выявленных пробелов.

## Цель работы

Разработать и исследовать методы автоматизированного формирования и актуализации научно-технических баз знаний на основе LLM и агентных технологий.

## Основные задачи

1. Разработать механизм загрузки и обработки научно-технических документов.
2. Реализовать извлечение терминов, определений и семантических отношений с использованием локальной LLM.
3. Разработать механизм формирования онтологий и графа знаний.
4. Реализовать алгоритмы выявления пробелов в базе знаний.
5. Разработать LLM-агента для поиска и анализа научных публикаций.
6. Реализовать проверку релевантности, новизны и достоверности извлекаемой информации.
7. Разработать механизм автоматизированного дополнения базы знаний и онтологий.
8. Провести экспериментальное исследование эффективности предложенного подхода.

## Архитектура системы

### 1. Формирование базы знаний

На вход системы поступает корпус научно-технических документов.

Документы проходят предварительную обработку, после чего локальная LLM извлекает:

- Научно-технические термины и определения.
- Сущности и семантические отношения.
- Классы и иерархические связи для формирования онтологий.
- Упоминания терминов и ссылки на источники.

На основе результатов формируются структурированная база знаний, граф знаний и онтологическое ядро.

### 2. Обнаружение пробелов в знаниях

Система анализирует накопленные знания и выявляет потенциальные информационные пробелы.

Примеры:

- Термин часто встречается в документах, но не имеет определения.
- Понятие недостаточно подробно описано.
- Отсутствуют ожидаемые семантические отношения.
- Разные документы содержат противоречивую информацию.

Выявленные пробелы используются для формирования задач актуализации.

### 3. Агент автоматизированной актуализации

LLM-агент выполняет следующий цикл:

1. Получает информацию об обнаруженном пробеле.
2. Формирует поисковые запросы.
3. Ищет научные публикации через доступные API и открытые источники.
4. Оценивает релевантность найденных материалов.
5. Проверяет документы на дубликаты.
6. Извлекает потенциально новые знания.
7. Сопоставляет их с существующей базой знаний.
8. Выполняет необходимые проверки и формирует обновления.
9. Дополняет базу знаний и при необходимости онтологическую структуру.

## Предполагаемый стек технологий

## Исследовательская часть

Основной исследовательский вопрос:

**Позволяет ли целенаправленный поиск научных публикаций на основе автоматически обнаруженных пробелов повысить полноту базы знаний по сравнению с традиционными методами её пополнения?**

Планируется сравнить следующие подходы:

1. Регулярное пополнение базы знаний новыми релевантными документами.
2. Пополнение с использованием LLM для определения новизны информации.
3. Агентное пополнение на основе автоматически обнаруженных пробелов.

### Критерии оценки

- Precision, Recall, F1 извлечения терминов и отношений.
- Точность выявления информационных пробелов.
- Доля корректно восполненных пробелов.
- Доля ошибочных и дублирующихся обновлений.
- Время и вычислительные затраты на актуализацию.

## Ожидаемые результаты

- Программный прототип системы формирования и актуализации базы знаний.
- Механизм извлечения терминов, отношений и формирования онтологий с использованием LLM.
- Алгоритм обнаружения пробелов в знаниях.
- LLM-агент автоматизированного поиска и анализа научных публикаций.
- Механизм контролируемого пополнения базы знаний.
- Экспериментальная оценка качества предложенного метода.

Дополнительно рассматривается реализация визуализации графа знаний и семантического поиска с использованием онтологий.
